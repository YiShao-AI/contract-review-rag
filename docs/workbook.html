Problem framing

Start with the decision, not the chatbot

Operating need

Institutional knowledge is valuable only when the person handling a live question can find the right resolution and verify it quickly.

Target decision

Which prior resolution or contract clause applies, what evidence supports it, and does the user have enough support to act?

Definition of done

A verified answer, a correction, or an informed escalation—not merely generated text.

My role: stakeholder discovery, workflow and data analysis, requirements, retrieval and citation design, implementation, evaluation, and rollout planning.
Two operating applications

The same retrieval pattern, applied to different decisions

Internal customer support assistant

Make repeated resolutions available to every shift

More than five years of support email threads and recorded calls held high-value institutional knowledge. Because customer questions repeated, past resolutions could shorten live lookup and reduce dependence on the memory of specific experienced agents.

The workflow added each new ticket and call to the knowledge base and returned source-linked answers through the company’s established messaging platform.

Contract QA assistant

Connect operating questions to the exact clause

A status board could show whether a contract was active, but it could not answer what the agreement said about revenue share, renewal, notice contacts, or deadlines.

The public implementation demonstrates ingestion, OCR, hybrid retrieval, source citations, and derived notice-deadline logic over a contract portfolio.

Make the corpus retrievable before asking it questions

Data issueWhy it mattersDesign response
Long, repetitive support historyEntire threads and calls are too noisy to retrieve as-is.Distill question, resolution, state, category, and date while retaining the original source link.
Scans and filled formsImportant entered values may be absent from the document text layer.Use text extraction plus OCR and merge recovered overlay content into the source representation.
Exact terms inside natural languageVector similarity can miss a precise identifier; keyword search can miss paraphrase.Fuse dense-vector and FTS5 candidates before generation.
Stale or conflicting sourcesA well-written answer can still be wrong if it uses an obsolete resolution.Retain source version and owner; route correction and stale-source review into maintenance.
Design decisions

Choices that connect technical behavior to business use

Hybrid retrieval over model fine-tuning

Knowledge changes continuously and users need traceability. Retrieval keeps new sources available without retraining and connects the answer to current evidence.

Source citations as a first-class feature

Verification is part of the operating decision. The source panel and document context are therefore product behavior, not an afterthought.

Existing channel over a new support UI

Meeting distributed agents in the company’s established workflow reduced training and adoption friction.

Local-first with deployment flexibility

The corpus and inference can remain local; a configurable hosted endpoint remains available where the approved deployment permits it.

What the current results show

  • The retrieval path consistently routes labeled questions to the intended documents.
  • Clause-level passage retrieval is strong enough to support the interactive source workflow.
  • Citation labels remain connected to the evidence shown to the user.

Next validation layer

  • Expand locked cases across unanswerable, conflicting, stale, and high-risk questions.
  • Collect user feedback at the answer level and review misses by category.
  • Track verified lookup time, escalation, adoption, corrections, and incidents.
